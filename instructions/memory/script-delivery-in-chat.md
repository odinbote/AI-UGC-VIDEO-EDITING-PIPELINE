Abik (2026-11-02): "I don't want md file all the time I just want script written. And this is not good, I want on to the point easy to understand way."

**Why:** The two explainer scripts came as long .md documents (decode tables, intake, shot columns, debug passes). Abik wants the words to say, not the paperwork. The Instagram feed v1 used mechanism words ("inbox", "flip it", "disk is slow") and was rejected as not easy to understand.

**How to apply:** Write the script in the chat message, as lines to read, ~25–30 s, ~80 words, plain everyday words, one idea per line, no engineering vocabulary in speech. Only make a file when Abik asks for one (the decode / shot column work can still be done, but not delivered as a document by default). Supersedes the "deliver as .md" step of [[script-trigger-workflow]]; the other rules there still hold (no "free", no "course", "mapped" at the close, CTA "Start at step one. fanout.sh").
